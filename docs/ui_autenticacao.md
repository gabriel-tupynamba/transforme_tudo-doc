# 🔐 Autenticação e Navegação Principal

Este módulo é responsável pelo fluxo de entrada do utilizador e pela apresentação da interface principal do Transforme Tudo. Todo o design foi pensado para reduzir a fricção e guiar o foco.

---

### 1. O Ponto de Partida (Boas-vindas e Login)
A primeira interação com o ecossistema. O ecrã de **Boas-vindas** apresenta a proposta de valor da aplicação com um design limpo, direcionando o atleta para o **Início de Sessão**. A segurança encontra a fluidez: campos de credenciais bem espaçados, contraste focado no *dark theme* e recuperação rápida de palavra-passe.

  <img src="../assets/Auth/Login.jpeg" width="220" />

### 2. Criação de Conta e Proteção de Dados
Para novos utilizadores, o ecrã de **Registo** capta as informações essenciais de forma ágil. Logo a seguir, o sistema exige a **Verificação de Conta** via email, garantindo a autenticidade do utilizador e mantendo a base de dados do Firebase limpa, segura e 100% auditável.

<p align="center">
  <img src="../assets/Auth/Register.jpeg" width="220" /> &nbsp;&nbsp;
  <img src="../assets/Auth/Verifying.jpeg" width="220" />
</p>

### 3. O Centro de Comando (Home e Abas de Treino)
A navegação foi desenhada para colocar o treino no centro da experiência. A **Home** é uma *dashboard* minimalista que atua como um gatilho para a ação ("Tudo pronto para hoje"). Ao aceder às abas, o sistema exibe métricas globais instantâneas, como a tonelagem movimentada, e permite visualizar todo o cronograma da semana.
